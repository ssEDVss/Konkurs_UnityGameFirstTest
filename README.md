# Konkurs_UnityGameFirstTest

Тестовый проект на **Unity 6**, созданный в формате тренировки на время при подготовке к конкурсу.

## 🎯 Цель проекта

Главная задача этой работы — провести честную проверку собственных навыков в условиях ограниченного времени:
* **Закрепить** то, что я уже умею делать уверенно (сборка сцен, базовая логика геймплея, спавн объектов, настройка UI и работа с префабами).
* **Выявить слабые места** и понять, какие темы и механики в Unity нужно подтянуть перед основным конкурсом.

## 🛠 Технологии и структура

* **Движок:** Unity 6 (`6000.6.6f1`)
* **Язык:** C#
* **Архитектура проекта:** код разделён на логические модули (`Core`, `Data`, `Gameplay`, `UI`), реализованы главное меню (`MainMenu`) и игровая сцена (`GameScene`).

## 🚀 Как запустить проект

1. Склонируйте репозиторий или скачайте архив с кодом.
2. Откройте проект через **Unity Hub** (рекомендуемая версия редактора — `6000.6.6f1` или новее).
3. Запустите сцену `Assets/Scenes/MainMenu.unity`.
